# 🏆 CaliTracker

A premium, ultra-lightweight (17KB) Calisthenics Workout Tracker. Built for performance, privacy, and simplicity.

## 🚀 Features
- **Modern UI:** Dark mode with neon accents and glassmorphism.
- **Dynamic Logger:** Track sets, reps, and weights for all your favorite movements.
- **Session Timer:** Stay on track with an integrated workout timer.
- **Progress Tracking:** Automatic streak counters and session history.
- **Offline First:** Works entirely offline using LocalStorage.
- **Cross-Platform:** Available as a PWA (Web) and a native Android APK.

## 📲 Install on Your Phone

### 🌐 Web App (Any Device / iOS)
You can use CaliTracker directly in your browser or install it as a PWA:
1. Open [https://GrimReaper-deadman.github.io/CaliTracker/](https://GrimReaper-deadman.github.io/CaliTracker/) on your phone.
2. Tap the **Share** button (iOS) or **Menu** (Android).
3. Select **"Add to Home Screen"**.

### 🤖 Android APK
Download the ultra-small (17KB) native app:
- **[Download CaliTracker.apk](https://github.com/GrimReaper-deadman/CaliTracker/raw/main/CaliTracker.apk)**

## 🛠 Tech Stack
- **Frontend:** Vanilla HTML5, CSS3, JavaScript.
- **Native Wrapper:** Android WebView with a lightweight Java bootstrap.
- **Storage:** Browser LocalStorage API.

## 📦 Local Development
1. Clone the repo:
   ```bash
   git clone https://github.com/GrimReaper-deadman/CaliTracker.git
   ```
2. Run a local server:
   ```bash
   cd CaliTracker
   python3 -m http.server 8080
   ```
3. Open `http://localhost:8080`.
